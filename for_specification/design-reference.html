Gauge Widgets — Design Reference

자동차 계기판 메타포의 데스크톱 플로팅 위젯 3종(Claude Code · Codex · Pomodoro). 모든 위젯은 140×140px 정사각 기준으로 설계되었고, 이 페이지에서는 가독성 확인을 위해 1.55배로 표시합니다. 각 상태는 동일 위젯을 다크/라이트 두 바탕 위에 나란히 올려 투명 배경에서의 가독성을 검증합니다.

Claude #D97757 Codex #46C2D4 Pomodoro #F0563D Caution #EBB13E Danger #E5484D

Claude Code — 8 states

메인 링 = 5시간 한도 잔량(12시 시작·시계방향). 안쪽 가는 링 = 7일 한도 잔량. 중앙 = 5시간 창 리셋까지 남은 시간(H:MM).

Codex — palette in states

동일 상태 언어가 한색(teal) 팔레트에서도 동일하게 동작하는지 확인.

Pomodoro — 3 states

보조 게이지 없음. 메인 링 = 현재 인터벌 잔량. 중앙 = 남은 분.

Design decisions

  • 보조 게이지 = 동심 내부 링. 하단 막대는 원형 본체와 충돌하는 사각 요소를 더하지만, 동심 링은 "같은 종류의 측정값, 한 단계 아래"라는 위계를 두께(3 vs 7)와 투명도(0.5)만으로 표현해 단일 계기판 언어를 유지한다.
  • Codex 색 = teal #46C2D4. 따뜻한 주황/토마토의 보색 축에 있는 한색이라 나란히 놓였을 때 즉시 구분되면서도 같은 채도 톤으로 조화롭고, Codex/OpenAI 계열의 teal 정체성과도 어긋나지 않는다.
  • 경고등 = 중앙 텔테일. 미로그인은 호박색 '키' 램프, 인증오류는 적색 '경고 삼각형(!)' 램프. 색(amber/red) + 기호 두 축으로 구분하고, 데이터가 없는 상태이므로 숫자 대신 램프를 중앙에 두어 점등된 계기판 등처럼 한눈에 읽히게 했다.
  • 틱 마크 = 유지(정제). 사용자 선호이자 계기판 메타포의 핵심 텍스처. 단 데이터는 연속 아크가 담당하고 틱은 균일한 48개 저투명 눈금으로 링 바깥을 감싸 '정밀 계기' 인상만 주도록 역할을 분리했다.
  • HOVER = 글로우 + 디스크 상승, 스케일 없음. 160ms로 아크 drop-shadow 글로우, 디스크 불투명도/그림자 상승, 숫자 순백 전환. 위젯을 키우는 스케일은 장난감처럼 보여 계기판 톤을 해치므로 배제.
  • frosted 디스크 = 적용. 흰 숫자가 밝은 바탕화면에서 사라지지 않으려면 일정한 어두운 기판이 필요하다. 반투명+blur 디스크가 라이트/다크 양쪽 가독성을 보장하고, 동시에 계기판 베젤 같은 물성을 부여한다.
  • 중앙 보조 퍼센트 = 생략. 링 충전량이 이미 잔량을 나타내므로 퍼센트 숫자는 주인공(리셋 시간)과 중복·경쟁한다. 중앙은 시간만, 잔량은 링만.
  • 중앙 포맷 = H:MM 통일. 5시간 창은 항상 0:00–4:59 범위라 시계/스톱워치처럼 읽히고, 뽀모도로의 단일 숫자와 한 가족으로 묶인다. 단위 글자 없이 가장 큰 자형을 확보.
